# Email and SMS Communications

## Purpose

Automated communication reduces missed appointments, support calls, and scheduling confusion.

## Transactional messages

- Quote request confirmation
- Estimate ready
- Booking confirmation
- Waiver signing request
- Agreement completed
- Payment confirmation
- Appointment reminder
- Crew on the way
- Dumpster delivered
- Pickup reminder
- Rental expiration warning
- Pickup confirmation
- Overage notice
- Final receipt
- Review request

## SMS consent

Transactional and marketing consent should be separate.

Store:

- Phone number
- Consent type
- Consent language shown
- Date and time
- Source page or form
- IP address when appropriate
- Opt-out timestamp
- Consent status

## SMS behavior

- Support STOP-based opt-out.
- Do not send marketing messages without marketing consent.
- Keep operational messages short.
- Include company identification.
- Respect local sending hours.
- Log delivery and failure status.

## Email behavior

- Send from a verified Barnes domain.
- Use responsive templates.
- Include booking number.
- Include contact information.
- Link to the secure customer portal.
- Avoid exposing sensitive information.
- Provide plain-text alternatives.

## Notification delivery tracking

Track:

- Queued
- Sent
- Delivered
- Failed
- Opened when supported
- Clicked when supported
- Opted out

## Failure handling

When a critical notification fails:

- Alert staff.
- Allow manual resend.
- Provide alternative communication method.
- Record every retry.
